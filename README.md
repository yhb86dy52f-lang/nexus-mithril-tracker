# NEXUS-MITHRIL // Tracker Personal

Proyecto personal, no comercial. Dashboard familiar para monitorear
mis propios dispositivos, mi auto y mis sensores de casa.

Nombre inspirado en Tolkien. Sin afiliación a ninguna empresa de defensa
o de rastreo satelital.

## Stack
- Backend: Fastify + SQLite
- Frontend: Vanilla JS + Leaflet
- Hardware: CalAmp (SMS) + ESP32 + BLE

## Uso
Solo para dispositivos de mi propiedad y con mi consentimiento.
